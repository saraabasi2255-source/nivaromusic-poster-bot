# بات دستیار شخصی NivaroMusic (نسخه‌ی خصوصی — فقط برای خودت)

این نسخه از پروژه طوری تغییر کرده که:
- ❌ هیچ‌جا (کانال یا هرکس دیگه) پست نمی‌کنه.
- ✅ فقط برای همون آیدی تلگرام خودت (`OWNER_ID`) جواب می‌ده.
- ✅ وقتی یه فایل صوتی برات می‌فرستی، کپشن رو طبق اسم آهنگ/خواننده می‌سازه،
  دکمه‌ی شیشه‌ای «نسخه‌های دیگه‌ی این آهنگ» رو می‌سازه، و فایل صوتی +
  کپشن + دکمه رو مستقیم توی همون چت خصوصی برات برمی‌گردونه.
- ✅ همچنان از همون دیتابیس D1 مشترک با بات اصلی استفاده می‌کنه (برای
  اینکه دکمه‌ی «نسخه‌های دیگه» بعدا کار کنه و بات اصلی هم آهنگ رو ببینه).

## مراحل راه‌اندازی

### ۱. دیتابیس مشترک
از پروژه‌ی بات اول، `wrangler.toml` رو باز کن، `database_id` زیر
`[[d1_databases]]` رو کپی کن و توی `wrangler.toml` همین پروژه جایگزین
مقدار فعلی کن (باید دقیقا همون دیتابیس باشه، نه یه دیتابیس جدید).

جدول‌های مخصوص این بات رو (اگه قبلا نساختی) بساز:

```bash
wrangler d1 execute song_search_db --remote --file=./schema.sql
```

### ۲. متغیرها
توی `wrangler.toml` بخش `[vars]`:
- `MAIN_BOT_USERNAME` = یوزرنیم بات اصلی (بدون @) — فقط برای ساختن لینک دکمه لازمه.
- `OWNER_ID` = آیدی عددی خودت توی تلگرام (با @userinfobot پیدا کن).

مقادیر محرمانه (توکن بات دومی که ساختی):

```bash
wrangler secret put POSTER_BOT_TOKEN
wrangler secret put POSTER_WEBHOOK_SECRET
```

### ۳. دیپلوی

```bash
npm i -g wrangler   # اگه نداری
wrangler login
wrangler deploy
```

### ۴. وصل کردن وبهوک

```bash
curl -X POST "https://api.telegram.org/bot<POSTER_BOT_TOKEN>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://nivaromusic-poster-bot.<subdomain>.workers.dev/webhook",
    "secret_token": "همون POSTER_WEBHOOK_SECRET",
    "allowed_updates": ["message", "callback_query"]
  }'
```

### ۵. کپشن دلخواه
بالای `src/index.js`، متغیر `CAPTION_TEMPLATE` رو به سلیقه‌ی خودت عوض کن
(`{title}` و `{performer}` خودکار جایگزین می‌شن)، بعد دوباره `wrangler deploy`.

## استفاده
1. توی چت خصوصی با این بات، فایل صوتی رو بفرست.
2. پیش‌نمایش کپشن رو تایید کن (یا عنوان/خواننده رو ویرایش کن).
3. اگه آهنگ مشابهی توی دیتابیس پیدا بشه ازت می‌پرسه این نسخه‌ی کدومه
   (یا «آهنگ جدید»).
4. بات همون فایل صوتی رو با کپشن کامل + دکمه‌ی شیشه‌ای، **فقط توی همون
   چت خصوصی برای خودت** برمی‌گردونه. هیچ‌جای دیگه‌ای پست نمی‌شه.
